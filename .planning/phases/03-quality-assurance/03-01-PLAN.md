**AppDelegate.swift** (13 IUOs on lines 22-37):
- These are `private var service: Type!` IUO declarations. Per D-18, IBOutlet-style IUOs in AppDelegate are an allowed exception because they are always initialized in `applicationDidFinishLaunching` before any use.
- Add comment above the block: `// Force unwrap safe: All properties initialized in applicationDidFinishLaunching before any access`

**SettingsWindow.swift**:
- Line 57: `window.contentView!.bounds` — replace with `guard let contentView = window?.contentView else { return }` and use `contentView.bounds`
- Line 181: `URL(string: "...")!` — replace with `guard let url = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility") else { return }` then `NSWorkspace.shared.open(url)`
- Line 196: Same pattern for Screen Recording URL

**SwitcherPanel.swift**:
- Line 27-28: `private var scrollView: NSScrollView!` and `stackView: NSStackView!` — these are set in init, add comment: `// Force unwrap safe: initialized in setupUI() called from init`
- Line 117: `NSScreen.screens.first!` — replace with `guard let screen = NSScreen.main ?? NSScreen.screens.first else { return }`

**WindowModel.swift**:
- Line 17: `NSImage(named: NSImage.applicationIconName)!` — replace with `NSImage(named: NSImage.applicationIconName) ?? NSImage()`

**AccessibilityService.swift**:
- Line 18: `focusedRef as! AXUIElement` — replace with `guard let focused = focusedRef as? AXUIElement else { return nil }` (function should return optional)

Fix all other SwiftLint warnings (line length, etc.) across all files. After fixing, run `swiftlint lint --config .swiftlint.yml --strict` and verify zero violations.
